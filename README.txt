MESSAGE CARD PROJECT

Files:
- index.html
- style.css
- script.js
- teacher-photo.jpg

How to run:
1. Keep all four files in the same folder.
2. Double-click index.html, or open it in a browser.
3. Click "Open My Greeting" to see the interactive effect.

You can personalize the message in index.html.
The design uses a soft blush/pink palette, elegant typography, a photo folder/card layout,
and a small JavaScript interaction while keeping the page professional.
